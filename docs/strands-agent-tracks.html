Phase 0 — 现有 Agent 产品化
Done

New features

  • Hooks 只读守卫：outreach_agent_hooks.py（ReadOnlyToolGuard，BeforeToolCallEvent.cancel_tool + AfterToolCallEvent 记录），使「agent 永不写 follow-up」成为代码级保证；
  • Bedrock Guardrails：BedrockModel(guardrail_id, guardrail_version, guardrail_trace) 接入，配置见 config.py / .env.example；
  • OTel 追踪：agent_telemetry.py（StrandsTelemetry 控制台 / OTLP 开关）+ Agent(trace_attributes) 携带 owner_id；
  • 测试用 FakeModel：tests/fake_strands_model.py 实现 Model 接口，驱动真实 agent loop；
  • 新测试 tests/test_outreach_agent_loop.py：读守卫拦截 / 白名单放行 / 生产接线 / 守卫单元，由 FakeModel 驱动真实 loop；另有 agent 超时用例（test_outreach_plan.py）。

Fixes

  • 修复 agent 被阻塞 / 超时时错误语义，未构建候选时快速返回；
  • agent 输出仍在 outreach_plan_client.invoke_outreach_agent 内按授权候选集二次校验（含 logger.error 告警）；
  • 确认 import 卫生：outreach_plan_agent / agent_telemetry / outreach_agent_hooks 顶层不引 strands，缺依赖时不破坏 ai_briefs.py 导入。

遗留 / 建议（来自 Phase 0 代码评审，供后续任务）： (1) 超时用 cancel_futures=True 无法中断已运行的 Bedrock 线程，建议传 cancel_signal=threading.Event 进 agent()； (2) 「shadow 观察」目标未完全落地：当前配置即为全阻断（guardrail_trace="enabled"），未接入 ApplyGuardrail 仅记录不阻断的 shadow 模式，误杀率需靠拦截日志观察（SDK 1.55.1 流式路径已解析 guardrail trace）； (3) guardrail_redact_output（默认 False）未暴露，学生 PII 输出脱敏待补； (4) 守卫对 Phase 2 的 MCP / context_manager="agentic" 注入工具会误拦，需改全阻断为分来源策略； (5) test_outreach_agent_loop.py 依赖 strands 安装，未装 requirements-bedrock.txt 时整组 skip，CI 需装依赖才能真验证。

Phase 2 — Agent 能力扩展
Open

New features

  • owner-scoped 只读工具：get_contact_history / get_open_follow_ups / get_teacher_notes，全走 require_owned_*；
  • 语音笔记真链路：boto3 + Amazon Transcribe 替换存根 → teacher_confirmed=false 草稿；

  • Phase 0 遗留 (4)：守卫改为按工具来源/前缀策略，放行 SDK 注入工具（context-management / MCP）而只对业务危险工具拒绝；

安全红线（贯穿所有阶段）

  • 工具一律 owner-scoped 只读：入口走 require_owned_*；
  • 教师确认制：agent 只产草稿（pending / teacher_confirmed=false），写入需教师确认；
  • fail-closed：超时 / 越权学生 / 结构异常一律拒绝（503），输出按授权候选集二次校验；
  • 候选上下文最小化：不含电话号码、provider ID、token、凭据；
  • 测试不触网：单测全部用 FakeModel / monkeypatch；
  • 不可动项：Contact Brief Lambda（外部已部署）、Twilio 拨号（Edge Function 独占）。
