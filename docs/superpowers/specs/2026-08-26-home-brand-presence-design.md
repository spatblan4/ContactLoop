# ContactLoop 首页品牌区视觉增强设计

## 背景

当前首页顶部导航的品牌标识、文字和右侧导航字号偏小，与中部 hero 主视觉的尺寸差距较大，导致页面上方视觉重量不足。目标是在保持 ContactLoop 现有浅色、克制 SaaS 风格的前提下，增强顶部品牌区，并重新平衡首屏上下层级。

## 设计方向

采用“品牌感更强”的方案：让顶部品牌单元和导航更容易被识别，同时使用轻量边框、阴影和 hover 状态增加结构感，避免加入厚重的装饰或改变页面信息架构。

## 具体改动

### 首页顶部导航

- `.home-nav` 高度调整为约 96px。
- `.home-brand` 的文字字号提升至约 23px，并保持现有 Space Grotesk、黑色 / coral 配色。
- `.home-brand .brand-mark` 放大至约 40px，并保持现有 coral 色、圆角和轻微旋转。
- 品牌 mark 与字标之间的间距提升至约 12px。
- `.home-nav-links` 字号提升至约 14px，链接间距提升至约 32px。
- 链接增加轻量胶囊式 hover 状态：浅 coral 背景、较深文字色、适度内边距和圆角；不增加独立按钮或复杂动效。
- 导航底部保留分隔线，并增加非常轻的向下阴影，帮助顶部与 hero 建立结构联系。

### 首屏 hero

- 保持现有两列布局、主标题和右侧产品视觉不变，避免改变核心叙事。
- 顶部 padding 略微收紧，减少顶栏与 hero 之间的断层。
- 适度增加 hero 的整体垂直空间，使增强后的顶栏与下方 proof 区有更平衡的呼吸感。
- hero 标题只做小幅比例校正，不让品牌区抢过主标题的主视觉地位。

### 下方信息区

- proof 区标题字号和说明字号做小幅提升，并增加与 hero 的分隔空间。
- privacy strip 保持现有浅绿色背景和内容结构，仅微调文字尺寸和垂直内边距。
- 不增加新的内容、卡片或装饰元素。

### 响应式行为

- 在 620px 以下：顶部高度回落到约 72px，品牌 mark 与字标缩小一级；右侧导航继续隐藏。
- 移动端 hero 保持单列布局，避免放大的品牌元素挤压标题和 CTA。
- 桌面端新增的胶囊 hover 状态不影响键盘焦点可见性和链接可点击区域。

## 范围与约束

- 只修改首页相关 CSS；不修改 dashboard、Supabase、数据逻辑和现有交互。
- 优先复用现有颜色变量、字体和组件样式。
- 不新增依赖，不替换现有 hero 图片。

## 验证标准

- 桌面端顶部 logo 和导航相对当前明显更有存在感，但 hero 标题仍是第一视觉焦点。
- 顶栏、hero、proof 区之间的垂直比例更均衡，不再出现上下过轻、中间过重的感觉。
- 620px 以下页面不出现顶部横向溢出，logo、hero 标题和 CTA 保持可读、可操作。
- `npm run build` 成功完成。
