# ContactLoop — Devpost 视频稿版本对照

> Hackathon: **Agents for Humans — Devpost**  
> Target: English demo video, maximum 5 minutes, ideal length around 4 minutes

## Version 1 — Full technical demo

**适合：**希望充分展示 Strands Agent、Supabase、Twilio、Amazon Bedrock 和教师审核机制时使用。

**旁白量：**约 715 词；实际录制约 4–4.5 分钟，取决于操作速度和停顿。

**特点：**技术信息完整，包含真实拨号、Agent 工具调用、数据可信来源和 Human-in-the-loop。

完整稿件：[[contactloop-devpost-video-script]]

## Version 2 — Condensed technical demo（推荐录制版）

**适合：**希望节奏更紧，同时保留黑客松评委最关心的技术亮点时使用。

**旁白量：**约 600 词；适合控制在 4 分钟左右，并给界面加载和电话截图留出余量。

完整稿件：[[ContactLoop Devpost Video Script — Condensed]]

## 选择建议

优先录制 **Version 2**。它不会删掉技术，而是把技术集中在一个高密度段落里：

- Strands Agent 自主选择 ContactLoop tools；
- Supabase 提供经过验证的通话数据；
- Amazon Bedrock 生成 Contact Brief；
- 教师审核后，AI 输出才成为最终记录。

如果第一次录制后时间明显充裕，再替换成 Version 1 的技术解释。
