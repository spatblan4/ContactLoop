dev 分支重构说明

分支：dev · 基线：e6fdea0 · 生成日期：2026-09-07 · 规范文档：docs/REFACTOR_SPEC.md

1. 概述

dev 分支汇聚了由 5 个并行 worktree 完成的全栈重构，并叠加了登录认证与部署支持：

  • 后端从零重建为 Python FastAPI 应用（backend/），保留 Supabase Postgres 为首选数据库，未配置连接时自动回退本地 SQLite。
  • 实体规范化：6 个业务实体全部增加审计字段（created_at / updated_at / created_by / updated_by）与软删除（deleted_at），新增 users、auth_tokens 两个认证实体。
  • DAO 层规范化：统一仓储接口（BaseDAO），所有查询自动过滤已删除行。
  • 完整 CRUD：所有实体补齐缺失/不完整的前后端 CRUD。
  • 本地账号登录：注册 / 登录 / 会话 / 登出，数据按用户隔离。
  • Docker 化部署：Dockerfile ×2 + docker-compose。

实体与规范

实体要点
studentsowner_id 关联账号；软删级联至全部子表
guardians标准 CRUD；每学生多监护人
contact_eventsattempt_number 服务端计算；触发跟进同步规则
follow_ups新增 completed_at；(学生, 监护人) 唯一开放跟进约束
teacher_notestyped / voice 两种来源
ai_contact_briefsdraft / approved / superseded 状态机 + approve / supersede 动作
users 新增email 唯一；PBKDF2-SHA256 密码哈希
auth_tokens 新增仅存 token 的 SHA-256 哈希；30 天有效期；可吊销

所有实体统一由 AuditMixin 提供审计五字段；DELETE 一律软删除，所有查询默认排除 deleted_at IS NOT NULL。

业务规则（原 Postgres 触发器逻辑服务端化）

  • 联系结果为 Connected 且已结束 → 自动完成该（学生 × 监护人）的开放跟进并记录 completed_at；
  • No Answer / Busy / Failed → 自动 upsert 开放跟进，到期时间 = 结束时间 + 1 天（可由调用方覆盖）；
  • 同一（学生 × 监护人）同时只允许一条开放跟进，冲突返回 409。

认证与数据隔离

  • 接口：POST /api/v1/auth/register · POST /auth/login · GET /auth/me · POST /auth/logout；
  • 令牌：Bearer token，Authorization: Bearer <token>；兼容 Supabase JWT（配置 SUPABASE_JWT_SECRET 时优先验签）与 X-User-Id；
  • 隔离：登录用户的全部列表查询与聚合（含 /data/load、/dashboard/summary）按 students.owner_id 过滤，写操作自动记录 created_by / updated_by；匿名访问不受限。

4. 前端（src/）

  • src/lib/api/：fetch 客户端（VITE_API_BASE_URL，支持 same-origin 相对模式）+ 每实体 API 模块 + 认证模块；
  • src/lib/supabase.js：兼容门面 —— 保留原有全部导出名，底层改走 FastAPI；新增 guardians / events / follow-ups / notes 全量 CRUD 导出；
  • src/lib/auth.js：未配置 Supabase 时自动走后端登录，返回结构保持兼容；
  • UI：学生详情内监护人增删改、教师笔记编辑/删除、跟进 dismiss/删除、联系记录删除；移除硬编码 profile；侧边栏 Sign out；首页锚点平滑滚动 + 高亮；
  • 模式：VITE_APP_MODE=authenticated（登录后按用户隔离数据）或 demo（免登录演示）。

5. 运行与部署

本地开发（SQLite）

# 后端
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 前端（仓库根目录，.env.local 已配置）
npm install
npm run dev   # http://localhost:5173

7. 已知边界

  • AI 摘要生成（POST /ai/contact-brief/generate）在未配置 provider 时返回 501；
  • Twilio 通话与 Supabase Edge 语音转写仍走原有链路；本地 SQLite 模式下语音走后端存根（保存文件、转写返回占位文案）；
  • 登录会话无自动续期：token 30 天后需重新登录。
